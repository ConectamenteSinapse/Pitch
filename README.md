# Pitch — ConectaMente

## Sobre o projeto

O **ConectaMente** é um projeto que propõe o uso da tecnologia e da gamificação para contribuir com o desenvolvimento da autonomia de pessoas com Síndrome de Down em atividades da rotina diária.

Por meio de um jogo sério com desafios, fases e progressão por níveis, buscamos proporcionar uma experiência interativa e acessível.

## Apresentação

Este repositório contém o vídeo de apresentação (*pitch*) do projeto ConectaMente, no qual apresentamos a proposta, o problema identificado, o público-alvo e os objetivos da solução.
